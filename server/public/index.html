Astra widgets MCP

A hosted MCP Apps server for astra-db-plugin: database overview, collection card, similarity search, and collection explorer widgets for Astra DB.

Endpoint: POST /mcp (streamable HTTP, stateless). Every request carries its own Astra credentials — nothing is stored server-side.

Authorization: Bearer <ASTRA_DB_APPLICATION_TOKEN>
X-Astra-Endpoint: https://<db-id>-<region>.apps.astra.datastax.com
# or append ?endpoint=<url> to the connector URL

Register it in ChatGPT's developer mode with API-key auth, or point any MCP client at /mcp.
